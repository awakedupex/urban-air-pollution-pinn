The continuous model is stable and well posed

Stability

Fourier stability

C ∝ exp(ik·x + σt) gives Re σ = −(D|k|² + λ) < 0: every mode decays; advection only shifts the phase.

Steady state

Equilibrium

Uniform source: C(t) → C* = S₀/λ, globally stable. With g(τ)/H(t) the solution settles into a daily cycle.

Structure

Positivity, mass

Maximum principle: C ≥ 0 if inputs are. Mass changes only through sources, removal and boundary flux.

Identifiability. An unrestricted source could absorb any residual, so S is restricted to q(x,y)·g(τ)/H(t), and D is weakly identifiable because Pe ≫ 1.

Stability: substitute a Fourier mode; the growth rate has negative real part for all wavenumbers, so short waves are damped by diffusion and all waves by removal; this is why we can spin the synthetic truth up for 24 hours and do not need an initial field for the PINN. Equilibrium: the uniform ODE dC/dt = S₀ − λC has the stable fixed point S₀/λ; the periodic forcing through the mixing height gives the night-time peaks we see in the data.
